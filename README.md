# University Portfolio — Vladislav Salii

A single-page developer portfolio for university applications (Computer Science / Cybersecurity / AI).

## Files

- `index.html` — the page: structure and content
- `styles.css` — all the styling (dark theme, layout, components)
- `script.js` — sticky nav, scroll-in animations, and the commendation lightbox

The favicon and the commendation letter are embedded directly in `index.html`.

## Running / hosting it

Open `index.html` in any browser to view it locally. To put it online, deploy the three files together:

- **GitHub Pages:** Settings → Pages → deploy from `main` / root
- **Netlify:** drag `index.html`, `styles.css`, and `script.js` in together

No build step and no dependencies. Fonts load from Google Fonts.
