About

A bit about me.

I'm Vladislav, a developer from Belgrade. I started young — writing little programs to do my own homework for me, like working out the HCF and LCM of numbers — and I never really stopped. That turned into automating the small things I do every day, and then into real projects: a school e-diary, a security scanner that finds exploitable bugs in code, booking sites for local studios, a Windows tool that keeps software in sync across machines, and a few bots and games along the way.

The thread through all of it is building things that run on their own. What pulls me now is where that meets security — the more we hand decisions over to software and AI, the more it matters that those systems can be trusted and can't be turned against the people who rely on them. That's what I want to work on: using computer science, and AI and security, to help keep people safe as this technology grows. Alongside code I study on the Cambridge curriculum, speak four languages, and dance competitively.

E-Diary

A digital school diary I built for Chartwell

My school's digital diary felt dated, so with a classmate I built a full replacement and presented it to the school's leadership. It has separate flows for students, teachers and admins: timetables, attendance, grades, homework, substitutions, reports and data imports. The front-end is plain HTML/CSS/JavaScript on Netlify; the back-end is a stateless Django API on Render that issues JWTs and scopes every query on the server by role, on top of Supabase (PostgreSQL, Auth and Storage). The school couldn't adopt it because of the rules around student data, but it made them re-evaluate and improve their own system, which is the part I'm proudest of.

Vemirix

A security scanner that finds what is actually exploitable in a codebase

Most security tools bury developers in hundreds of warnings. Vemirix connects to a GitHub repository, clones it into a sandbox and runs three scanners: secret detection (pattern matching plus Shannon entropy, with evidence masked before it is stored), dependency checks against the OSV vulnerability database, and static analysis. Alongside Bandit for Python I wrote my own taint-tracking rules for JavaScript/TypeScript, Go, Java, Ruby, PHP and C# that follow user input across files into SQL and command injection, SSRF, path traversal and XSS. Findings are de-duplicated by fingerprint and scored 0–100 by a deterministic risk model, and an optional AI layer explains each one and writes an ordered fix plan, shown in a web dashboard and exported as a PDF report.

Orchestrator

Systems · C# / .NET 8
C#

A Windows service that keeps software in sync across a fleet of PCs with no server: a private GitHub repo is the control plane. Agents diff a manifest against what is installed, verify every download by SHA-256, report back via heartbeats on a separate branch and update themselves by hashing their own executable. A web console adds Wake-on-LAN and an audited, always-visible remote-control session.

AI-Driven Channel

AI & Automation · Python
Python

A Python service that runs the Telegram channel Signals of the Future with no human in the loop. An asyncio scheduler fires twice a day, an LLM (Llama 3.3 on Groq, or GPT) writes a post in a fixed voice from a few-shot prompt, an image is generated or drawn with Pillow, and the Bot API publishes it. Every step has a fallback, so a failing provider never stops a post.
