About

A bit about me.

I'm Vladislav, a developer from Belgrade. I started young — writing little programs to do my own homework for me, like working out the HCF and LCM of numbers — and I never really stopped. That turned into automating the small things I do every day, and then into real projects: a school e-diary, booking sites for local studios, a Windows tool that keeps software in sync across machines, and a few bots and games along the way.

The thread through all of it is building things that run on their own. What pulls me now is where that meets security — the more we hand decisions over to software and AI, the more it matters that those systems can be trusted and can't be turned against the people who rely on them. That's what I want to work on: using computer science, and AI and security, to help keep people safe as this technology grows. Alongside code I study on the Cambridge curriculum, speak four languages, and dance competitively.

Orchestrator

A Windows tool that manages software across many machines

This is the biggest thing I've built. It's a small Windows service that keeps software in sync across a lot of machines, using a GitHub repo as the one place you control everything from. You edit a list of programs, and each machine installs, updates or removes them on its own — delete something and it uninstalls everywhere on the next check. It verifies every download with a checksum, and there's a small web console so you don't have to edit JSON by hand.

CONTROL PLANE
GitHub is the only infrastructure — zero servers
