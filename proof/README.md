# Certificate images

Put photos or scans of the certificates here with exactly these names. Each "View certificate" button on the site only appears once its file exists.

| File | Shown on |
| --- | --- |
| `igcse.jpg` | Cambridge IGCSE results |
| `as-level.jpg` | Cambridge AS Level results |
| `ielts.jpg` | IELTS Academic card |
| `olympiad.jpg` | STEM Olympiad card |

Before uploading, blur or cover personal details: date of birth, candidate and centre numbers, the IELTS test report number, home address and any ID numbers. Keep your name, the subjects, grades and the date visible.

Keep each image under about 500 KB (around 1600 px wide is plenty), so the page stays fast.
